APP FLUTTER

 
Actúa como un Arquitecto de Software Senior especializado en Flutter, UX/UI, SaaS Dashboards, Business Intelligence y aplicaciones Enterprise.

Tu objetivo es generar una aplicación Flutter completa que replique visualmente un dashboard analítico premium similar a los dashboards modernos de Stripe, Linear, Vercel, Notion Analytics, Tableau, Power BI y plataformas Fintech de última generación.

========================================
OBJETIVO GENERAL
========================================

Crear una aplicación Flutter completamente funcional para Android, iOS, Web, Windows, Linux y MacOS.

La aplicación debe ser responsive y adaptarse automáticamente a:

- Mobile
- Tablet
- Desktop
- UltraWide

Debe soportar:

- Material Design 3
- Dark Mode
- Light Mode
- Animaciones fluidas
- Arquitectura limpia
- Componentes reutilizables
- Preparada para API REST
